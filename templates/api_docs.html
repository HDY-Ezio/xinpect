开发者 API

把你的 AI 助手接上煋鉴：在后台生成一把密钥交给它，之后你让它检查代码，它直接调我们的接口， 扣的是你的会员积分，不用再打开网页、不用打包上传。

接口是给程序用的；人手动扫一次代码还是走网页上传，两条路扣的是同一份积分。

去后台生成密钥 还不是会员？看定价

接口总览

服务地址：https://xinpect.xingwangzhineng.com

用途 方法与路径 说明
提交代码 POST /api/v1/scan 小任务直接返回报告；大任务返回任务号，交给下一步去取
查进度／取结果 GET /api/v1/scan/status/{scan_id} 就是上一步返回的 poll_url
取消排队 POST /api/v1/scan/{scan_id}/cancel 排队中取消不扣积分
验证地址通不通 GET /api/v1/scan 不带参数，返回接口自述，不需要密钥

密钥的生成、停用都在后台页面点，不用手调接口。

三步接上来

第一步
先有会员和积分

接口只对会员开放。没有会员，调用会返回「请先开通会员」。

第二步
在后台生成一把密钥

密钥以 xk_ 开头，只显示一次，当场复制保存。丢了就停用旧的、再生成一把。

第三步
交给你的 AI

后台「扫描密钥」页有一键复制的指令块，粘给扣子、ChatGPT、通义的助手就能用；也支持 MCP 配置。

提交代码要带什么

请求头带密钥，请求体是 JSON。

位置 字段 必填 说明
请求头 X-API-Key 是 后台生成的那把 xk_ 密钥
请求体 code_files 是 对象：键是文件名，值是文件内容
请求体 language 否 默认 auto 自动识别；也可写 python、javascript 等

整包提交就行，不用自己拆文件。单次上限 500 个文件 / 10MB / 20 万行，超了会返回 413 并提示联系管理员。

调用示例（Python）

把下面这段里的密钥换成你自己的，就能跑。 

import time
import requests

BASE = "https://xinpect.xingwangzhineng.com"
KEY  = "xk_你的密钥"

# 1) 提交：键是文件名，值是文件内容
r = requests.post(
    BASE + "/api/v1/scan",
    headers={"X-API-Key": KEY, "Content-Type": "application/json"},
    json={"code_files": {"app.py": open("app.py", encoding="utf-8").read()},
          "language": "python"},
    timeout=600,
)
data = r.json()

# 2) 大项目会先受理，拿到任务号就轮询（poll_url 是相对路径，要自己拼域名）
while data.get("status") in ("processing", "queued", "pending"):
    time.sleep(8)
    data = requests.get(BASE + data["poll_url"],
                        headers={"X-API-Key": KEY}, timeout=60).json()

# 3) completed 时这一份 JSON 里就是完整报告
print(data["score"], data["grade"], len(data.get("issues", [])))

想用 curl 也行：curl -H "X-API-Key: xk_..." -H "Content-Type: application/json" -d '{"code_files":{"a.py":"print(1)"}}' https://xinpect.xingwangzhineng.com/api/v1/scan

返回里都有什么

小任务当场就是 completed；大任务先给任务号，靠 status 判断到哪一步了。

字段 含义
status queued 排队中（不扣积分）／pending 正在检查／ completed 已完成／failed 失败（积分自动退）／cancelled 已取消
scan_id 这次任务的编号
poll_url 查进度用的路径（相对路径，前面拼上服务地址）
progress / progress_text 0~100 的百分比，以及「正在检查哪个文件」的说明
score / grade 质量分和等级。等级为 S / A / B / C / D；只提交单个文件或小片代码时返回 文件级，表示这是片段评估、不构成项目级评级（分数照给）
issues 问题清单：每条含位置、严重度、说明和改法
credits_used 这次实际扣了多少积分

积分怎么扣

  • 按实际代码行数扣，和网页上传同一个价、同一个池子。
  • 排队不扣钱：排到了、真正开始检查那一刻才扣；排队中可随时免费取消。
  • 失败自动退：检查失败这一次的积分会退回来。
  • 同一份代码重复提交，会直接返回上次的报告（省时间），但仍按一次计。
  • 调用频率上限 10 次 / 60 秒，超了返回 429。

报错对照表

状态码 意思 怎么办
400 请求体不对：不是 JSON、缺 code_files、内容为空 确认 Content-Type: application/json，code_files 里要有内容
401 没带密钥，或密钥无效、已停用 检查请求头 X-API-Key，必要时后台重新生成
402 不是会员，或积分不够 先开通会员／充值
403 密钥存在但已停用 后台重新生成一把
413 单次提交超出 500 文件 / 10MB / 20 万行 分批提交，或联系管理员定制
429 60 秒内调用超过 10 次 等一会儿再叫
500 我们这边出错了 重试一次；还不行就从帮助中心找我们
