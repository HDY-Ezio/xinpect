v7.0 2026-10-30

🏢 团队版正式上线

面向小团队和企业推出团队协作版，与个人版独立运行：

  • 付费即建团：扫码购买团队版，付完钱自动创建团队，你直接就是管理员
  • 一个账号两个身份：个人身份 / 团队身份一键切换，各花各的积分
  • 共享积分池：团队一个积分池，成员共用，不扣成员个人积分
  • 子账号管理：邀请成员、权限归团队管，全程留痕、账号不可抵赖
  • 统一治理：治理看板 + 质量门禁，卡住不达标的代码
  • 标准对照报告：一键生成对照 CWE / OWASP Top 10 的标准对照报告
🆓 免费试扫，30 秒见结果

官网首页新增「免费试扫」，不用注册，贴一段代码 30 秒内出结果，附「健康度打分」（满分 100，A~E 评级）。

🎯 检测能力大幅提升
  • 六类核心注入漏洞（SQL / 命令 / 路径遍历 / XSS / LDAP / XPath）误报率全部降到 0
  • 六类注入检出率从 40%~65% 提升到 74%~93%（旧样本口径，不与现行 OWASP Benchmark 2,740 个 Java 测试用例全量基准混用）
  • 同一份代码多次扫描结果完全一致，杜绝偶发波动
  • 同台实测领先竞品（本条原写的百分比为旧样本口径，2026-11-03 起已停用，避免与现行全量基准混用）：OWASP Benchmark 2,740 个 Java 测试用例全量基准误报 0 条、漏报 123 条，两类都公开
🛠️ 开发者工具链升级
  • 边写边扫（watch）：命令行实时监听文件改动，自动重扫变更文件，省积分省时间
  • 一键修复（fix）：扫出问题直接生成补丁（确定性规则 + AI 双引擎），补丁生成后自动回验确认漏洞关闭，一键创建草稿 PR 供人工 review 合并（深度扫描专属）
🎨 官网改版

全新品牌视觉；漏洞知识库新增 LDAP 注入、XPath 注入、信任边界等条目；语言口径统一为 23 种编程语言。

🎁 老用户补偿

本次 v7.0 版本更新期间，服务器更新导致部分用户的使用受到了影响，为表歉意，我们决定对 2026 年 10 月 30 日前注册的老用户每人补偿 50 积分，登录后可在首页顶部领取（每人限领一次）。

💰 关于计费调整的说明

为什么调整：煋鉴上线初期，为了让更多开发者先体验起来，我们一直以远低于市场行情的起步价提供服务。但起步价终究不能长久，随着产品逐步稳定、检测能力经过多轮迭代，我们决定把价格回调到一个正常、可持续的水平。

调整之后，价格依然实惠。我们拿市场上同类服务的真实价格做个对比（3000 行代码深度审计）：

服务市场价
人工代码审计1500 ~ 3000 元（0.5~3 元/行）
资深工程师按人天1500 ~ 3000 元/天
一份代码审计报告5000 元起
煋鉴深度检查（调整后）约 90 元

调整之后，煋鉴的深度检查仍然比人工审计便宜 16 ~ 33 倍。

具体调整：

  • 计费粒度从「每 300 行」细化到「每 100 行」，按实际代码量精确计费，小片段不再被高估
  • 快速检查保持亲民，智能检查（AI 语义）、深度检查（AI 深度 + PoC 实弹验证）体现真实价值

老用户完全不受影响：你账户里已有的积分，永久按原价消耗，一分不贬值。这次调整只针对新购买。

🔒 14项安全加固

基于第三方渗透测试反馈，完成14项安全修复：

新增 R 语言专属安全引擎，覆盖命令注入（system()/system2()）、SQL注入、硬编码凭证、eval(parse()) 代码注入等10类检测。支持语言数达到 31种。

🧠 JavaScript 检测增强

命令注入检测升级为文件级智能分析——当文件引入 child_process 模块时，自动追踪 exec()/execSync() 调用，不再因跨行代码遗漏检出。

🐛 用户反馈问题修复

  • LLM 问题描述优化：AI 分析报告中的问题描述更加精确，从模糊表述（如"括号不匹配"）升级为包含具体行号和修复方式的详细说明
  • 扫描引擎稳定性：修复引擎偶发崩溃导致服务不可用的问题
📊 报告体验优化
  • 扫描报告配色统一为品牌深蓝主色调，与官网视觉一致
  • 专业版报告模板上线，结构参考 SonarQube/Checkmarx 行业标准

v6.0 2026-10-12

🛡️ 业务逻辑安全检测（核心升级）

传统 SAST 工具能发现 SQL 注入、XSS 这类技术漏洞，但对业务逻辑漏洞基本无解：

  • 用户 A 能不能访问用户 B 的订单？
  • 支付金额能不能被前端篡改？
  • 同一个订单能不能重复支付？
  • 退出登录后 Session 真的失效了吗？

v6.0 的 E2 安全检测引擎新增 50+ 条业务逻辑安全规则，覆盖 7 大维度：

密码安全8条弱密码策略、明文存储、弱哈希算法
认证授权10条越权访问、JWT 误用、RBAC 缺陷
输入验证8条业务层输入校验缺失、类型绕过
会话安全6条Session 固定、会话劫持、并发限制
支付安全8条金额篡改、重复支付、退款漏洞
数据安全6条敏感数据泄露、数据完整性破坏
审计日志4条关键操作审计缺失、日志注入
其他变更
  • 引擎架构统一为 E1-E7 + AI语义分析 + PoC验证，命名更清晰
  • 检测规则总数从 2400+ 提升至 2500+
  • 新增 Agent 安全检测和高级业务逻辑检测
