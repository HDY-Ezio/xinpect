📖 接入指南

  1. 获取 API Key
    在上方「API Keys」区域复制你的 API Key，或前往 Agent 接入 页面创建新的 Key
  2. 添加 Secrets
    在 GitHub 仓库中进入 Settings → Secrets and variables → Actions，点击 New repository secret，添加：
    Name: XINPECT_API_KEY Value: 你的煋鉴 API Key
  3. 创建 Workflow 文件
    在仓库中创建 .github/workflows/xinpect.yml，复制以下内容：
    name: 煋鉴代码扫描 on: push: branches: [main, master, develop] pull_request: branches: [main, master, develop] concurrency: group: xinpect-${% raw %}{{ github.ref }}{% endraw %} cancel-in-progress: true env: XINPECT_SCAN_MODE: {{ config.get('default_scan_mode', 'quick') }} XINPECT_THRESHOLD: "{{ config.get('default_threshold', 60) }}" XINPECT_FAIL_ON_BELOW: "true" jobs: xinpect-scan: name: 煋鉴代码扫描 runs-on: ubuntu-latest timeout-minutes: 10 steps: - name: 检出代码 uses: actions/checkout@v4 with: fetch-depth: 1 - name: 收集代码文件 id: collect run: | python3 -c " import json, os, sys extensions = { '.py', '.js', '.ts', '.jsx', '.tsx', '.java', '.go', '.c', '.cpp', '.h', '.hpp', '.cs', '.rb', '.php', '.swift', '.kt', '.scala', '.rs', '.vue', '.svelte', '.html', '.css', '.scss', '.sql', '.sh', '.yaml', '.yml' } ignore_dirs = { 'node_modules', '.git', '__pycache__', '.venv', 'venv', 'dist', 'build', '.next', '.nuxt', 'target', 'vendor', } files = {} for root, dirs, filenames in os.walk('.'): dirs[:] = [d for d in dirs if d not in ignore_dirs] for fn in filenames: if os.path.splitext(fn)[1].lower() in extensions: fp = os.path.join(root, fn) rp = os.path.relpath(fp, '.') try: sz = os.path.getsize(fp) if 0 < sz <= 512000: with open(fp, 'r', encoding='utf-8', errors='ignore') as f: files[rp] = f.read() except: pass if len(files) >= 200: break if len(files) >= 200: break if files: with open('/tmp/xinpect_files.json', 'w') as f: json.dump(files, f) print(f'Collected {len(files)} files') " - name: 执行煋鉴扫描 id: scan if: steps.collect.outcome == 'success' env: XINPECT_API_KEY: ${% raw %}{{ secrets.XINPECT_API_KEY }}{% endraw %} run: | python3 -c " import json, sys, urllib.request with open('/tmp/xinpect_files.json') as f: code_files = json.load(f) payload = json.dumps({ 'code_files': code_files, 'scan_mode': '${% raw %}{{ env.XINPECT_SCAN_MODE }}{% endraw %}', 'threshold': int('${% raw %}{{ env.XINPECT_THRESHOLD }}{% endraw %}'), 'repo': '${% raw %}{{ github.repository }}{% endraw %}', 'branch': '${% raw %}{{ github.ref_name }}{% endraw %}', 'commit_sha': '${% raw %}{{ github.sha }}{% endraw %}', }).encode() req = urllib.request.Request( 'https://xinpect.xingwangzhineng.com/api/ci/scan', data=payload, headers={ 'Content-Type': 'application/json', 'X-API-Key': '${% raw %}{{ secrets.XINPECT_API_KEY }}{% endraw %}', 'X-Requested-With': 'XMLHttpRequest', } ) with urllib.request.urlopen(req, timeout=300) as resp: result = json.loads(resp.read()) with open('/tmp/xinpect_result.json', 'w') as f: json.dump(result, f) print(f'Score: {result.get(\"score\")}') print(f'Passed: {result.get(\"passed\")}') print(f'Report: {result.get(\"report_url\")}') - name: 质量门禁检查 if: steps.scan.outputs.skipped != 'true' run: | python3 -c " import json, sys with open('/tmp/xinpect_result.json') as f: r = json.load(f) if not r.get('passed'): print(f'::error::质量门禁未通过! 评分 {r[\"score\"]} 低于阈值') print(f'报告: {r[\"report_url\"]}') sys.exit(1) print(f'✅ 煋鉴质量门禁通过 (评分: {r[\"score\"]})') "
  4. 完成！
    推送代码或提交 PR 时会自动触发扫描。扫描结果会作为 CI 检查项显示，不通过门禁阈值的提交会被拦截。

  4. 完成！
    推送到 main/master/develop 分支或创建 Merge Request 时自动触发扫描。也可在 Pipeline 页面手动触发。
  1. 下载 CLI 工具
    下载煋鉴命令行扫描工具，支持 Python 3.7+，无需额外依赖：
    🐍
    xinpect-cli.py
    Python CLI 工具 (无需安装)
  2. 配置 API Key
    # 方式一：环境变量 export XINPECT_API_KEY=你的API_Key # 方式二：命令行参数 python xinpect-cli.py --api-key 你的API_Key
  3. 执行扫描
    # 扫描当前目录（使用默认 quick 模式） python xinpect-cli.py # 扫描指定目录 python xinpect-cli.py --path /path/to/project # 使用深度扫描模式 python xinpect-cli.py --mode deep # 设置质量门禁（低于 70 分返回非零退出码） python xinpect-cli.py --threshold 70 --fail-on-below # 忽略测试文件 python xinpect-cli.py --ignore "tests,docs,mock" # 输出 JSON 格式结果 python xinpect-cli.py --json
  4. 集成到任意 CI 系统
    CLI 工具适用于 Jenkins、CircleCI、Azure DevOps 或任何支持 Python 的 CI 系统。只需在流水线中调用：
    # Jenkins Pipeline 示例 stage('Code Quality') { steps { sh 'python xinpect-cli.py --path src --mode quick --fail-on-below --threshold 60' } }
  1. API 概览
    煋鉴提供 RESTful API，可以集成到任何自定义工作流：
    接口 方法 说明
    /api/ci/scan POST 提交代码文件进行扫描
    /api/scan/github POST 通过 GitHub 仓库 URL 扫描
    /api/ci/config GET/POST 获取/更新 CI 配置
    /api/scan/{id}/share POST 生成分享链接
    /api/badge/{id}.svg GET 获取评分徽章 SVG
  2. 请求示例
    curl -X POST "https://xinpect.xingwangzhineng.com/api/ci/scan" \ -H "Content-Type: application/json" \ -H "X-API-Key: 你的API_Key" \ -H "X-Requested-With: XMLHttpRequest" \ -d '{ "code_files": { "src/main.py": "文件内容...", "src/utils.py": "文件内容..." }, "scan_mode": "quick", "threshold": 60, "repo": "my-project", "branch": "main", "commit_sha": "abc123" }'
  3. 响应示例
    { "status": "ok", "scan_id": "ci_abc123", "score": 85, "passed": true, "issues": { "total": 3, "critical": 0, "warning": 2, "info": 1 }, "scan_mode": "quick", "report_url": "https://xinpect.xingwangzhineng.com/report/ci_abc123", "badge_markdown": "[![煋鉴评分](.../api/badge/ci_abc123.svg)](...)", "elapsed": 2.35, "file_count": 12 }
  4. 添加评分徽章到 README
    [![煋鉴评分](https://xinpect.xingwangzhineng.com/api/badge/{scan_id}.svg)](https://xinpect.xingwangzhineng.com/report/{scan_id})
