常见问题

支持哪些文件格式？

支持 Python、JavaScript、TypeScript、Java、Go、C/C++、PHP、Ruby、Swift、Kotlin、Rust、Shell、SQL、HTML/CSS 等 40+ 种代码文件，也支持 ZIP/TAR.GZ 压缩包上传。

一次能上传多少文件？

支持多文件同时上传，总大小不超过 50MB。建议只上传核心业务代码，无需上传 node_modules、.git 等依赖或版本控制目录，系统会自动过滤。

上传的代码安全吗？会被保存吗？

代码仅用于扫描分析，扫描完成后临时文件自动清理。报告数据加密存储，仅你本人可查看，不会用于任何训练或第三方用途。

适合什么场景？

适合快速检测单个文件或少量代码片段，比如你在写代码时想快速检查某段代码的质量，直接粘贴过来即可，无需创建文件。

对代码长度有限制吗？

没有严格的字符数限制，但建议单次粘贴不超过 5000 行。如果项目较大，建议使用「上传文件」或「GitHub 仓库」方式扫描完整项目。

支持哪些 GitHub 仓库格式？

支持标准 GitHub 链接，如 https://github.com/user/repo，也支持指定分支 https://github.com/user/repo/tree/branch。直接粘贴浏览器地址栏的链接即可。

私有仓库怎么扫描？

勾选「这是私有仓库」后，填写你的 GitHub Personal Access Token。Token 可在 GitHub Settings → Developer settings → Personal access tokens 中生成，只需勾选 repo 权限即可。Token 仅用于本次克隆，不会存储。

仓库太大怎么办？

系统会自动过滤 node_modules、.git、dist、build 等无关目录，最多扫描 200 个代码文件。如果仓库文件超过限制，建议指定特定分支或目录进行扫描。
